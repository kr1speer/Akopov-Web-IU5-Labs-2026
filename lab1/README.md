## 3. Задание

### 3.1. Основное задание

Создать статический интерфейс веб-приложения, связанного с тематикой **заказа на производство самолета**.  
Интерфейс должен позволять представить процесс выбора параметров, условной комплектации и взаимодействия пользователя с системой.

Необходимо:
- реализовать структуру страницы на HTML;
- оформить интерфейс через CSS;
- избегать устаревших подходов (inline-стили);
- обеспечить читаемость и логичность интерфейса.

---

### 3.2. Дополнительное задание

Разработать многостраничный сайт, где каждая страница отвечает за отдельный логический блок:

- `HomePage.html` — вводная информация  
- `WorkGoalPage.html` — цель работы  
- `CalculatorPage.html` — интерфейс выбора параметров самолета  
- `AboutPage.html` — сведения об авторе  

Все страницы объединены общей навигационной панелью.

---

## 4. Как реализовано (теория и фрагменты кода)

### 4.1. Семантика и навигация

Для построения структуры используются семантические элементы HTML, что делает код более понятным и логически организованным.

Навигация реализована через верхнюю панель с ссылками. Активный раздел выделяется визуально, что помогает пользователю ориентироваться.

```html
<header>
    <div class="topnav">
        <a href="./HomePage.html">
            <img src="logo.svg" alt="Boeing">
        </a>
        <a href="./WorkGoalPage.html">Цель работы</a>
        <a class="active" href="./CalculatorPage.html">Калькулятор</a>
        <a href="./AboutPage.html">Об авторе</a>

        <div class="theme-select">
            <label>Тема:</label>
            <select>
                <option>Тёмная</option>
                <option>Светлая</option>
            </select>
        </div>
    </div>
</header>
```
### 4.2. Организация интерфейса

Контент разбит на отдельные визуальные блоки (карточки), что делает интерфейс более удобным для восприятия.

Каждая страница содержит центральный элемент, в котором отображается основная информация.
```html
<section>
    <article class="content-card">
        <h1>Цель работы</h1>
        <p>
            Изучение инструментов HTML и CSS и разработка интерфейса,
            соответствующего заданной предметной области.
        </p>
    </article>
</section>
```
Основной функциональный блок (интерфейс выбора параметров самолета):
```html
<div class="calculator">
    <div id="result" class="result">0</div>

    <div class="buttons">
        <div>
            <button class="my-btn secondary">C</button>
            <button class="my-btn secondary">+/-</button>
            <button class="my-btn secondary">%</button>
            <button class="my-btn primary">/</button>
        </div>
    </div>
</div>
```
Такая структура позволяет легко масштабировать интерфейс и добавлять новые элементы.

### 4.3. Стилизация и визуальные эффекты

Оформление выполнено в едином стиле с использованием темной цветовой схемы и акцентных элементов.

Применяются эффекты наведения, тени и плавные переходы.
```css
.content-card {
  background: rgba(10, 26, 47, 0.85);
  border-radius: 20px;
  padding: 30px;
  color: white;
}

.my-btn {
  width: 60px;
  height: 60px;
  background: #1e3a5f;
  color: white;
  transition: 0.1s;
}

.my-btn.primary {
  background: #0078d2;
}

.my-btn.secondary {
  background: #5a6c7e;
}

.my-btn:hover {
  transform: translateY(-2px);
}
```
Дополнительные элементы интерфейса:
```css
.topnav a.active {
  border-bottom: 4px solid white;
}

footer {
  text-align: center;
  padding: 15px;
  color: white;
}

mark {
  background: #0078d2;
  color: white;
}
```
