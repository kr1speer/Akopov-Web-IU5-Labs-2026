## 3. Задание

### 3.1. Основное задание

Разработать JavaScript-логику для управления калькулятором комплектации самолета.

Необходимо реализовать:
- получение элементов из DOM-дерева;
- обработку пользовательских действий (нажатий кнопок);
- выполнение арифметических операций;
- вывод результата в поле `result`.

---

Расширить функциональность с учетом предметной области:

## 4. Теория и реализация (Примеры из кода)

### 4.1. Доступ к DOM и обработка событий

**Теория:**  
Для взаимодействия с интерфейсом используется механизм событий `addEventListener`. Это позволяет отделить логику приложения от HTML-разметки. Инициализация выполняется после полной загрузки DOM.

**Пример из кода:**

```javascript
// ActiveCalculator.js
document.addEventListener('DOMContentLoaded', () => {
    const outputElement = document.getElementById('result');
    const digitButtons = document.querySelectorAll('[id^="btn_digit_"]');

    digitButtons.forEach(button => {
        button.addEventListener('click', () => {
            const val = button.textContent === '000' ? '000' : button.textContent;
            handleInput(val);
        });
    });
});
```

### 4.2. Логика инженерных вычислений и унарные операции
Для уменьшения дублирования кода используется функция высшего порядка applyUnary. Она принимает операцию как аргумент и применяет её к текущему значению.

**Пример из кода:**

```javascript
// ActiveCalculator.js
const usdExchangeRate = 79.06;

const applyUnary = (func) => {
    if (!selectedOperation) {
        a = func(parseFloat(a || 0)).toString();
        displayNumber(a);
    } else {
        b = func(parseFloat(b || 0)).toString();
        displayNumber(b);
    }
};

document.getElementById('btn_custom')
    .addEventListener('click', () => applyUnary(x => x / usdExchangeRate));

document.getElementById('btn_op_sqrt')
    .addEventListener('click', () => applyUnary(x => Math.sqrt(x)));
```
### 4.3. Управление состоянием интерфейса и смена тем
Изменение внешнего вида реализуется через управление CSS-классами. JavaScript отвечает только за переключение состояний, а стили описаны в CSS.

**Пример из кода:**

```javascript
// ChangeTheme.js
const themeSelect = document.getElementById('themeToggle');

if (themeSelect) {
    themeSelect.addEventListener('change', (event) => {
        const selectedTheme = event.target.value;

        if (selectedTheme === 'light') {
            document.body.classList.add('light-theme');
        } else {
            document.body.classList.remove('light-theme');
        }
    });
}

document.getElementById('btn_display_color')
    .addEventListener('click', () => {
        document.getElementById('result').classList.toggle('alt-color');
    });
```
### 4.4. Динамическое масштабирование и обработка исключений

Для корректного отображения больших чисел реализована адаптация размера шрифта. Также предусмотрена защита от переполнения и ошибок вычислений.

**Пример из кода:**

```javascript
// ActiveCalculator.js
function adjustFontSize(value) {
    const outputElement = document.getElementById('result');
    const length = value.length;

    if (length > 9 && length <= 12) {
        outputElement.style.fontSize = "1.4rem";
    } else if (length > 12 && length <= 27) {
        outputElement.style.fontSize = "1.1rem";
    } else if (length > 27) {
        outputElement.textContent = "Error";
    }
}
```
